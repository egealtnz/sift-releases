# Sift releases

Installers for [Sift](https://egealtnz.github.io/sift-site/): Gmail with built-in categories.
This repository only holds release files. The Windows and Android apps check here for updates.

- **Windows:** `Sift-Setup-<version>.exe`. Installed apps update themselves.
- **Android:** `Sift-<version>.apk`. The app offers new versions with one tap.

Privacy policy: https://egealtnz.github.io/sift-site/privacy.html
